# Gnosis Keyboard Autocorrect Extensions

This directory contains dictionary data extensions for Gnosis Keyboard.

## Hinglish Vocabulary Extension
- **Primary File**: `words_hinglish.txt`
- **Mirrors**: `hinglish.txt`, `words.txt`
- **Total Words**: 4,704+
- **Usage**: Automatically downloaded by Gnosis Keyboard to power Hinglish auto-correct, swipe suggestions, and candidate predictions.
